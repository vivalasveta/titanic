Пересмотрев культовый фильм Джеймса Кэмерона 1997 года, я решила проверить, есть ли у главного героя Джека Доусона реальные шансы на спасение и каковы они в сравнении с его возлюбленной Розой. Мне было интересно посмотреть на ситуацию не через призму голливудской драматургии, а через сухие цифры статистики.

##  О проекте

В этом проекте я провела статистический анализ данных пассажиров «Титаника», чтобы выявить ключевые закономерности катастрофы. С помощью инструментов Python я посчитала фактические вероятности выживания в зависимости от:

- класса билета;
- пола;
- возраста;
- порта посадки.

## Главный вопрос исследования

> Остался бы Джек в живых, если бы его судьба зависела не от сценария, а от математических расчетов?

##  Стек технологий

- **Python** Pandas, NumPy — для обработки и анализа данных;
- **Matplotlib / Seaborn** — для визуализации результатов.
